# The vocabulary faster-whisper is told to expect, one entry per line.
#
# ONE FILE, TWO READERS, so that what the measurement measures is what the
# sidecar runs: src/config.ts reads it for the STT_HOTWORDS default, and
# dev/scripts/stt-vocab-check.py reads it through hints.py. It used to be a
# string literal in config.ts with a SECOND copy in the script's env default —
# identical by hand, and nothing would have said so when they drifted.
#
# Blank lines and lines starting with # are ignored. Order is the order the
# decoder sees; an entry may contain spaces ("RTX 3090").
#
# KEEP IT SHORT. faster-whisper truncates the hint tokens at half the model's
# context, and everything in this slot competes with the audio for the
# decoder's attention, so every entry added makes every other entry weaker.
# That is measurable, and it is why a candidate addition is run against the
# EXISTING cases as well as the new ones before it lands here.
